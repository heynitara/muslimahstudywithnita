# Muslimah Study 🌷

Web app interaktif ringan untuk belajar, merencanakan aktivitas, mencatat, dan melakukan ibadah tracking.

## Struktur
- `index.html` — halaman utama
- `style.css` — desain responsive
- `script.js` — fitur interaktif
- `data.js` — data materi dan quiz

## Fitur
- Dashboard statistik
- Islamic Study
- Muslimah Planner + To-do List
- Pomodoro 25 menit
- Ibadah Tracker
- Knowledge Quiz + skor otomatis
- My Notes
- Daily Motivation
- Search sederhana
- Dark mode
- Local Storage
- Responsive mobile/tablet/desktop
- Tanpa framework dan tanpa backend, cocok untuk GitHub Pages

## Deploy GitHub Pages
1. Buat repository baru di GitHub.
2. Upload semua file dalam folder ini ke repository.
3. Buka **Settings → Pages**.
4. Pada Source pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Simpan, lalu tunggu GitHub Pages menerbitkan aplikasinya.

> Catatan: font Google Fonts digunakan sebagai peningkatan tampilan; aplikasi tetap dapat berjalan tanpa backend.
